1. KONTEKS & TUJUAN
--------------------------------------------------------------------------------
Sistem mencatat absensi murid menggunakan satu USB RFID reader tipe HID/
keyboard emulator yang dicolok langsung ke PC Windows aplikasi.

- Server, database SQLite, halaman admin, dan halaman scanner berjalan di PC
  yang sama.
- Reader mengetik UID ke jendela scanner lalu mengirim Enter.
- Tidak ada HP, OTG, Wi-Fi, QR, hotspot, akses LAN, atau firewall khusus.
- Scanner dibuka sebagai jendela Microsoft Edge app dan dapat pula dibuka di
  browser lain melalui http://127.0.0.1:<port>/scan.
- Admin dibuka di tab/jendela browser lokal yang terpisah.
- Server hanya bind ke 127.0.0.1. Port utama 8000, dengan fallback ke port
  8001 sampai 8010 bila diperlukan.

2. TECH STACK
--------------------------------------------------------------------------------
Backend:
- Python 3.11+, FastAPI, Uvicorn, Jinja2, python-multipart.
- SQLite bawaan Python dengan WAL, foreign keys, dan busy timeout.
- openpyxl untuk import/export Excel.

Frontend:
- Jinja2, HTML, JavaScript vanilla, HTMX lokal, dan Pico.css lokal.
- Scanner tidak memakai input field sebagai penerima UID. JavaScript menangkap
  keydown pada document dan mengirim buffer saat Enter.

Packaging:
- PyInstaller mode folder (onedir).
- Tidak ada qrcode, psutil, NoSleep.js, atau aset/dependensi jaringan HP.

3. ARSITEKTUR UMUM
--------------------------------------------------------------------------------
[USB RFID Reader] --keyboard events--> [Windows PC]
                                      |
                    +-----------------+-----------------+
                    |                                   |
             [Browser Admin]                    [Edge app Scanner]
             /admin dan /api/admin              /scan
                    |                                   |
                    +---------- FastAPI ---------------+
                                      |
                              SQLite + backup

Semua endpoint hanya dapat diakses melalui loopback. Endpoint admin tetap
memeriksa request.client.host dan menolak selain 127.0.0.1 atau ::1.

Endpoint inti:
- GET  /scan
- GET  /api/ping             health-check lokal untuk script Windows
- POST /api/tap              menerima UID scanner
- GET/POST /admin/*          halaman dan tindakan admin
- POST /api/admin/...        tindakan admin berbasis JSON bila sesuai

4. MODE JARINGAN
--------------------------------------------------------------------------------
Tidak ada mode jaringan. Server selalu bind 127.0.0.1 dan tidak menerima
koneksi dari Wi-Fi, LAN, hotspot, atau perangkat lain.

- Tidak ada deteksi IP.
- Tidak ada kandidat adapter.
- Tidak ada QR.
- Tidak ada endpoint refresh jaringan.
- Tidak ada firewall rule.
- /api/ping hanya health-check dari PC sendiri, bukan heartbeat HP.

6. DATABASE DAN API ABSENSI
--------------------------------------------------------------------------------
Pertahankan skema database, migrasi yang ada, WAL, foreign keys, dan backup.
Pertahankan seluruh perilaku /api/tap:
- normalisasi UID;
- berhasil, duplikat, tidak dikenal, tidak aktif;
- log tap;
- idempotensi yang sudah ada bila masih dikirim client_tap_id;
- age_ms bila masih digunakan;
- pendaftaran kartu yang sudah diuji.

Refactor USB-only tidak mengubah tabel, query inti, rekap, atau Excel.

7. API ADMIN DAN PENDAFTARAN KARTU
--------------------------------------------------------------------------------
Daftarkan Kartu dilakukan dari dialog di halaman Data Murid, bukan dari
jendela scanner.

- Tombol membuka dialog untuk satu murid.
- Input dialog otomatis fokus dan membaca UID dari reader keyboard.
- Enter mengirim JSON ke endpoint admin lokal, misalnya
  POST /api/admin/santri/{student_id}/daftar-kartu.
- Server memvalidasi student_id dan UID lalu memakai logika registrasi yang
  sama seperti sebelumnya.
- Setelah berhasil, tampilkan popup sederhana "Kartu berhasil terdaftar".
- Dialog tetap terbuka, input dikosongkan, dan fokus kembali agar operator dapat
  mendaftarkan kartu berikutnya.
- Jika UID sudah dipakai murid lain, tampilkan pesan gagal dan dialog tetap
  terbuka agar operator dapat mencoba kartu lain.
- Tidak perlu polling status registrasi.

9. HALAMAN SCANNER (/scan)
--------------------------------------------------------------------------------
Tujuan: satu reader USB, satu PC, satu jendela scanner.

- Tampilan gelap dengan teks besar dan feedback warna.
- Tidak ada input field RFID.
- document.addEventListener("keydown", ...) mengumpulkan karakter UID.
- Enter mengirim buffer ke POST /api/tap, lalu buffer dikosongkan.
- UID pendek, karakter modifier, dan buffer yang terlalu lama ditangani secara
  aman tanpa mengubah normalisasi server.
- Tampilkan hasil berhasil, sudah absen, kartu belum terdaftar, kartu terdaftar,
  dan murid tidak aktif.
- Tap duplikat cukup memberi feedback "Sudah absen"; tidak perlu antrean
  offline karena server berada pada PC yang sama.
- Tidak ada NoSleep, ping jaringan, banner koneksi putus, localStorage queue,
  atau client-id khusus HP.
- Saat document.hasFocus() bernilai false, tampilkan popup/peringatan yang
  jelas: "SCANNER TIDAK AKTIF - klik jendela ini". Peringatan boleh berupa
  dialog/overlay ringan, bukan layar merah penuh. Keydown tidak diproses
  sebelum jendela kembali fokus.
- Saat fokus kembali, peringatan ditutup dan scanner aktif lagi.

12. SKRIP WINDOWS
--------------------------------------------------------------------------------
Start-Absensi.bat:
- bekerja dari folder aplikasi;
- cek /api/ping di 127.0.0.1 untuk menghindari instance ganda;
- jalankan server dengan --host 127.0.0.1;
- tunggu health-check berhasil;
- buka admin di browser pada /admin;
- buka scanner pada jendela terpisah dengan:
  msedge.exe --app=http://127.0.0.1:<port>/scan
- bila msedge.exe tidak tersedia, tampilkan pesan jelas; /scan tetap dapat
  dibuka manual di browser lain.

Matikan-Absensi.bat memanggil endpoint shutdown lokal.

Install-Firewall.bat dihapus. Tidak ada referensi firewall di script,
dokumentasi, atau panduan.

13. KEAMANAN DAN PRIVASI
--------------------------------------------------------------------------------
- Bind hanya ke 127.0.0.1.
- Admin dan endpoint admin menolak client selain 127.0.0.1 atau ::1.
- Tidak ada endpoint yang mengekspos daftar murid ke jaringan.
- /api/tap hanya mengembalikan informasi hasil tap yang diperlukan.
- Validasi input, query SQL berparameter, Jinja2 autoescape, dan batas upload
  Excel tetap dipertahankan.
- Tidak ada akses internet, CDN, QR, Wi-Fi, hotspot, atau firewall automation.
